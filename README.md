# Cherry
Это язык программирования, написанный на Python.

# ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ:
Писать код в формате ".cherry". Чтобы запустить свою программу, запускаете файл main.py и вводите путь к файлу с кодом.

# КОМАНДЫ:
print - вывод данных (0.1.0 alpha). Синтаксис для обычного текста: print"текст". Замените 'текст' на текст который вы хотите вывести. Синтаксис для переменных: print переменная. Замените 'переменная' на название вашей переменной. Со списком тоже самое что и с переменной. Синтаксис для элементов списка: print список<индекс>. Замените 'список' на название вашего списка, а 'индекс' на индекс вашего элемента (подсчёт идёт с нуля). print timeinfo делает тоже самое что и timeinfo.

int - тип переменных integer (целые числа) (0.1.0 alpha). Синтаксис для переменной int: int переменная = число. Замените 'переменная' на название вашей переменной, а 'число' на ваше целочисленное значение.

str - тип переменных string (строки) (0.1.0 alpha). Синтаксис для переменной str: str переменная = строка. Замените 'переменная' на название вашей переменной, а 'строка' на вашу строку (строки исключительно в двойных кавычках).

list - тип переменных list (списки) (0.2.0 alpha)

write - ввод данных (0.2.0 alpha)

timeinfo - вывод информации о дате и времени (0.2.0 alpha). Чтобы вывести информацию о дате и времени, просто напишите на отдельной строке timeinfo.

math.random - вывод случайного числа в указанном диапазоне (0.2.0 alpha). Синтаксис для команды: math.random начало_диапазона конец_диапазона. Замените 'начало_диапазона' на начало диапазона, а 'конец_диапазона' на конец диапазона.

math.square - вывод указанного числа в квадрате (0.2.0 alpha). Синтаксис для команды: math.square число. Замените 'число' на ваше число.

math.sqrt - вывод квадратного корня из числа (0.2.0 alpha). Синтаксис для команды: math.sqrt число. Замените 'число' на ваше число.

math.power - вывод указанного числа, возведённого в указанную степень (0.2.0 alpha)

wait - останавливает программу на указанное время (0.2.0 alpha). Синтаксис для команды: wait время. Замените 'время' на нужное вам время в секундах.

math.pi - выводит число Пи (0.2.0 alpha)

math.e - выводит число Эйлера (0.2.0 alpha)

folder - создаёт папку с указанным названием (0.2.0 alpha). Синтаксис для команды: folder"название". Замените 'название' на название вашей папки. Учтите! В название входит не только само название, но и путь к папке. Если написать просто название, папка создастся в той же папке что и файл 'main.py'.

folder.delete - удаляет папку с указанным названием (0.2.0 alpha). Синтаксис для команды: folder.delete"название". Замените 'название' на название вашей папки. Учтите! В название входит не только само название, но и путь к папке. Если написать просто название, папка создастся в той же папке что и файл 'main.py'.

file - создаёт файл с указанным названием (0.2.0 alpha). Синтаксис для команды: file"название". Замените 'название' на название вашего файла. Учтите! В название входит не только само название, но и расширение файла, и путь к файлу.

file.delete - удаляет файл с указанным названием (0.2.0 alpha). Синтаксис для команды: file.delete"название". Замените 'название' на название вашего файла. Учтите! В название входит не только само название, но и расширение файла, и путь к файлу.

file.edit - редактирует текст в указанном файле (0.2.0 alpha). Синтаксис для команды: file.edit"название" "текст". Замените 'название' на название вашего файла, а 'текст' на текст который вы хотите записать в файл. Учтите! В название входит не только само название файла, но и расширение файла, и путь к файлу.

rename - переименовывает указанный файл/папку (0.2.0 alpha). Синтаксис для команды: rename"старое_название" "новое_название". Замените 'старое_название' на текущее название вашего файла/папки, а 'новое_название' на новое название вашего файла/папки. Учтите! В название входит не только само название но и расширение файла, и путь к файлу/папке.
